# EDIYESTHRIFTS

A responsive five-page website for a women's plus-size thrift vendor, styled with deep green, warm ivory, and floral rose accents.

## Pages

- `index.html`: home and social links
- `about.html`: brand introduction
- `whatsapp.html`: WhatsApp contact
- `instagram.html`: Instagram profile
- `facebook.html`: Facebook page

## Run

Open `index.html` directly in a browser, or run `npm start` for a local static server.

## Customize

- Change the social destinations in `script.js` (`SOCIAL_LINKS`).
- Change colors, typography, and the homepage hero image path in `styles.css`.
- `assets/hero-dress.jpg` is the plus-size floral dress photo used on the homepage.
- `assets/edt1.jpg` through `assets/edt4.jpg` are distinct dress photos used by the story and social pages.
- Social icon marks are stored locally in `assets/whatsapp.svg`, `assets/instagram.svg`, and `assets/facebook.svg`.

The site has no build step or runtime dependencies.
